# HADI.STUDIO portfolio

Static site for GitHub Pages (HTML, CSS, JS only). All paths are relative, so it works under `/Hadi-Studio/`.

## Deploy
1. Copy everything in this folder into the root of the `HadiAlii/Hadi-Studio` repository (replace the old `index.html`).
2. Commit and push to `main`.
3. In **Settings > Pages**, choose *Deploy from a branch*, `main`, `/ (root)`.
4. Open https://hadialii.github.io/Hadi-Studio/ after the build finishes.

## Edit content
All projects, titles and file paths live in `js/data.js`. Add DESIGN3R work by putting files in `assets/design3r/<category>/` and adding items to its `groups` list.

## Notes
- Images are web-optimised WebP copies; videos are the original files with fast-start enabled (one 136 s video was re-encoded to reduce size).
- The video `sabeel-ashura-2026-6th-muharram.mp4` was renamed from its original Unicode filename for web safety.
